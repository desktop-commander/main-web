How it works in a chat

You ask in ChatGPT. Desktop Commander runs the commands on the connected computer and ChatGPT reports back.

ChatGPTwith Desktop CommanderExample
In ~/code/storefront, check my branch, switch to feature/checkout-copy, change the checkout button to "Place order", run the tests and show me the diff.

Illustrative example. Commands and output depend on your project.

Three things to start with

Each one works with the tools already in your repo.

Work on a Git branch

It checks the current branch and working tree, switches to the branch you name, makes the change, and shows you the diff so you can review it before committing.

Try: "Check my branch and working tree, then switch to feature/checkout and show me the diff after the change."

Run your tests

ChatGPT runs the test suite your repo already has, reads the failures, edits the code, and reruns the tests.

Try: "Run the tests and explain any failures before changing anything."

Type and lint checks

It runs tsc, ESLint and the other checks your project uses, applies fixes across files, and runs the checks again.

Try: "Run the type and lint checks and fix what they report."

Set up in two steps

No config files, no API keys. About three minutes.

1

Add the plugin in ChatGPT

Open Desktop Commander in the ChatGPT plugin directory, add it to your account, and sign in.

2

Connect your computer

After you sign in, follow the steps shown to connect the computer with your repo. ChatGPT then uses the files and development tools already there.

Then give ChatGPT its first task

Use Desktop Commander to open my repo at [path]. Show me the current branch, uncommitted changes and recent commits before we change anything.

Paste it into ChatGPT once your computer is connected. Replace [path] with the folder of your repo.
