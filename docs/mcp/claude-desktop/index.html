100% local MCP

Everything happens on your machine

Claude Desktop already runs on your computer, so Desktop Commander plugs in as a local MCP server. No cloud bridge, no middleman, no waiting.

  • Runs on your machine

    Desktop Commander is a local MCP server. It starts with Claude Desktop, works directly on your files and terminal, and needs no extra account.

  • Nothing extra leaves your machine

    Desktop Commander uploads nothing. Only what Claude reads in your conversation goes to the model, the same as any text you paste into a chat.

  • Free and open source

    The most popular file and terminal MCP, with 1M+ weekly downloads. Same server powers Cursor, Windsurf, and VS Code setups.

Setup

Install it your way

One click from the Claude directory, or one command in your terminal.

  • A

    From the Claude directory

    Open Desktop Commander in the Claude connectors directory and add it to Claude Desktop. Easiest path, no terminal needed.

  • B

    With one command

    Prefer the terminal? Run the installer below (needs Node.js v18 or newer), then restart Claude Desktop.

$ npx @wonderwhy-er/desktop-commander@latest setup
