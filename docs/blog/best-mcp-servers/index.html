The 22 best MCP servers (2025 and 2026)

November 25, 2025 By Karlina Sara Rozkalne
MCP

Karlina Sara Rozkalne

Karlina is a guest content author exploring topics of AI, MCPs, and automation in collaboration with the Desktop Commander team.

As the Anthropic MCP (Model Context Protocol) ecosystem expands, developers now have access to hundreds of high-quality servers across nearly every domain. We've rounded up the best MCP servers and organized them by category and use case, so you can quickly find the right stack for your workflow. Below, you'll find an MCP server list with a comparison table in each category with an overview of:
  • Difficulty level
  • Platform compatibility
  • Use-case fit

Top MCP servers by category

Development & version control

1. GitHub MCP Server Connects AI directly to repositories for managing commits, PRs, issues, and branches. Essential for version control automation and code review workflows. One of the most widely used MCP servers across Claude Desktop, Cursor, and other AI development tools. 2. GitLab MCP Server Built for GitLab Premium and Ultimate users. Enables AI-powered CI/CD pipeline inspection, merge request management, and secure code review. Uses OAuth 2.0 authentication. Ideal for enterprise teams with self-hosted GitLab environments and complex DevOps workflows. 3. Docker MCP Server Build, run, and inspect containers directly through AI commands. Perfect for debugging services, generating Dockerfiles, and managing reproducible development environments. A top choice for developers using containerized workflows in Cursor and Claude Desktop.

Productivity & communication

4. Slack MCP Server Automates Slack workflows with AI-powered message drafting, channel summaries, and workspace insights. Eliminates context-switching by letting Claude interact with conversations, threads, and channels directly. Great for team productivity and communication automation. 5. Notion MCP Server Official server providing read/write access to Notion pages, databases, and docs. Streamlines content creation, knowledge management, and project planning. Particularly powerful for teams managing structured information and collaborative documentation workflows. 6. Discord MCP Server Community-built servers that enable AI to send messages, read channels, manage reactions, and automate server tasks. Useful for community managers and moderators who need real-time communication automation and sentiment analysis across Discord communities. 7. Google Drive MCP Server Search, read, categorize, and manage files across Google Drive. Excellent for document summarization, research organization, and team resource management. Integrates seamlessly with shared drives and collaborative workspaces for knowledge retrieval.

Data & database

8. Postgres MCP Server Run natural-language SQL queries, analyze schemas, and explore relational data. Built for analysts and backend developers who need fast database insights without leaving their AI workflow. Supports complex joins, aggregations, and data modeling assistance. 9. MongoDB MCP Server Query and manipulate document-based datasets with AI assistance. Enables schema exploration, collection filtering, and NoSQL query design. Perfect for rapid prototyping with unstructured data and flexible document models that evolve over time. 10. ClickHouse MCP Server Official read-only server from ClickHouse for blazing-fast analytics on massive datasets. Columnar storage and high concurrency make it ideal for AI-generated queries. Built specifically for performance-heavy analytical workloads requiring real-time insights. 11. Supabase MCP Server Official server with 20+ tools: table design, migrations, SQL queries, database branching, project management, and TypeScript type generation. Combines Postgres, authentication, and storage. Perfect for full-stack developers building modern backend-powered applications.

File & system operations

12. Filesystem MCP Server Official foundational server for secure local file operations: read, write, edit, search, and manage directories. Essential for Claude Code and Cursor users. Provides granular permission controls and supports complex codebase refactoring workflows. 13. Desktop Commander A local-first MCP server focused on filesystem and terminal interactions. Also allows users to launch apps, organize files, and manage windows. Transforms Claude into a true desktop assistant. Ideal for users who want comprehensive system control through natural language.

Search & research

14. Brave MCP Server Privacy-first search delivering current, high-quality results without tracking. Enables research, source citation, and content summarization. Excellent for analysts and content creators who prioritize data privacy while conducting comprehensive web research. 15. Perplexity MCP Server Official server with fast search, deep research across multiple sources, and advanced reasoning tools. Provides citation-rich results with recency filtering. Built for precision research tasks requiring multi-step analysis and source verification. 16. Tavily MCP Server Official server offering real-time search, content extraction, web crawling, and site mapping via Tavily API. Includes 1,000 free monthly credits. Optimized for fast factual lookups, competitive research, and automated content discovery workflows. 17. Exa MCP Server Official server from Exa AI offering web search, GitHub code context retrieval, company research, and deep research capabilities. Searches billions of repos and docs for token-efficient code examples. Strong for developers and researchers needing comprehensive web intelligence. 18. Context7 MCP Server Fetches version-specific documentation and code examples directly from official sources. Eliminates outdated suggestions and hallucinated APIs. Essential for developers working with rapidly evolving frameworks or less common languages requiring current documentation.

Maps & location

19. Google Maps MCP Server Query locations, generate routes, calculate travel times, and analyze geospatial data. Essential for logistics planning, location-based services, and workflows requiring accurate mapping intelligence. Supports address validation and distance calculations.

Cloud & infrastructure

20. AWS MCP Servers Manage EC2, S3, IAM, CloudWatch, and other AWS services through AI. Automate deployments, inspect logs, optimize costs, and generate infrastructure templates. The most comprehensive cloud MCP ecosystem for AWS-centric development teams. 21. Azure MCP Server Official Microsoft server supporting 40+ Azure services, including Storage, Cosmos DB, PostgreSQL, AI Search, and Key Vault. Uses Entra ID authentication. Built for enterprise teams deeply integrated with Microsoft's cloud ecosystem. 22. Cloudflare MCP Server Cloudflare offers official MCP implementations and the Workers MCP framework for custom deployments. Manage Workers, KV, R2, D1, DNS, and security rules. Also includes MCP Server Portals for centralized connection management.

Awesome MCP servers for specific roles

Here are the MCP server examples for different roles. Note that this isn't an exhaustive list, but a snapshot of the available options.

Developers

These are the best MCP servers for coding, offering tight integration for back-end, front-end, and full-stack development.
  • Docker MCP Server – Build and debug containerized applications. Generate Dockerfiles and inspect running containers efficiently.
  • GitHub MCP Server – Manage pull requests, review code, create commits, and navigate repositories without leaving your IDE.
  • JetBrains MCP Server – Access IDE features like code formatting, refactoring, and running configurations through external AI clients.
  • Supabase MCP Server – Design database schemas, write migrations, manage authentication, and generate TypeScript types for full-stack apps.

Data analysts

These servers eliminate the friction of writing complex SQL or NoSQL queries manually, letting you focus on extracting insights rather than syntax.
  • PostgreSQL MCP Server – Write complex SQL queries, perform joins and aggregations, and analyze relational data through natural language.
  • MongoDB MCP Server – Explore NoSQL collections, filter documents, design queries for unstructured data and flexible schemas.
  • Supabase MCP Server – Run analytics queries, create database branches for testing, and manage data pipelines with built-in auth.

DevOps

These servers help orchestrate containers, validate deployments, and maintain CI/CD workflows without manual intervention.
  • Docker MCP Server – Orchestrate multi-container environments, debug services, validate deployments, and optimize container configurations.
  • GitHub MCP Server – Automate CI/CD workflows, inspect pipeline failures, manage infrastructure-as-code repositories, and review deployment PRs.
  • Playwright MCP Server – Automate browser testing, validate UI workflows, generate test scripts, and debug frontend integration issues.

Knowledge workers

These servers help manage documentation, coordinate team workflows, and keep information synchronized across multiple tools.
  • Notion MCP Server – Create and update documentation, manage project databases, organize team knowledge bases, and draft content collaboratively.
  • Zapier MCP Server – Connect Gmail, Sheets, CRM tools, and task managers to automate repetitive workflows across platforms.
  • Figma MCP Server – Extract design specs, access component libraries, and sync design tokens for developer-designer collaboration.
  • Slack MCP Server – Draft messages, summarize channel discussions, automate notifications, and search conversation history across workspaces.

Best MCP servers for different clients

Different AI clients excel with specific MCP servers based on their design and primary use cases. Here's how to match servers to your preferred client for optimal workflow integration.

Claude Desktop

Claude Desktop works seamlessly with both local and remote MCP servers, and these are the best MCP servers for users who want comprehensive file management, team collaboration, and system control.
  • Filesystem MCP Server – Full local file system access for reading, writing, editing, and organizing files across projects.
  • GitHub MCP Server – Complete repository management, including commits, branches, PRs, and issues directly from Claude conversations.
  • Google Drive MCP Server – Search, summarize, and organize cloud documents across personal and shared team drives seamlessly.
  • Slack MCP Server – Automate team communication: draft replies, summarize threads, search channels, and trigger workflow notifications.
  • Desktop Commander – Execute terminal commands, launch applications, automate file operations, and control system-level desktop functions.

Cursor

Since Cursor is purpose-built for developers, the best MCP servers for Cursor focus on code intelligence, version control, and automated testing.
  • JetBrains MCP Server – Leverage IDE features like intelligent refactoring, code navigation, and configuration management within Cursor.
  • GitHub MCP Server – Streamline version control: commit code changes, manage branches, review PRs without switching contexts.
  • Playwright MCP Server – Generate and run browser automation tests, validate UI components, debug frontend workflows efficiently.
  • Desktop Commander – Access local file system operations, run terminal commands, and perform rich text editing operations directly within your code workflow.

Claude Code / VS Code Agents

The best MCP servers for Claude Code prioritize codebase navigation, repository management, and development environment control.
  • Filesystem MCP Server – Navigate codebases, refactor files, search across directories, and manage project structures through AI.
  • GitHub MCP Server – Handle repository operations: push commits, create branches, resolve merge conflicts, track issues.
  • Docker MCP Server – Build containers, inspect logs, manage development environments, and troubleshoot containerized applications.

Conclusion

The MCP ecosystem has matured significantly, moving from experimental integrations to production-ready tools that genuinely improve how we work with AI. The best MCP servers listed here represent the most reliable, well-maintained options available, each solving real problems for specific workflows. The key is choosing servers that match how you actually work. Start with one or two that address your biggest friction points, then expand as you discover new automation opportunities. FAQ

Which MCP servers work with Claude? ▾
All MCP servers work with Claude Desktop through local configuration or one-click desktop extensions (.mcpb files). Claude on the web (claude.ai) requires a paid plan (Pro, Max, Team, or Enterprise) to connect to remote MCP servers through the Integrations feature. Some of the best Claude MCP servers include GitHub, Filesystem, Desktop Commander, Notion, Supabase, and Brave Search, depending on whether you're coding, researching, or writing.

Which MCP server providers offer free trials or money-back guarantees? ▾
Unlike traditional software, most MCP hosting providers don't offer money-back guarantees. However, most official MCP servers are open-source and free to use locally. The best risk-free option is to start with open-source servers hosted locally or use free remote endpoints before investing in hosting infrastructure.
